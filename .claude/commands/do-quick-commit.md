## Quick Commit Command

This command quickly commits all current changes with an automatically generated detailed description based on the actual changes made.

### WORKFLOW

1. **ANALYZE CHANGES**
   ```bash
   # Get current status
   git status --porcelain

   # Get diff statistics
   git diff --stat
   git diff --cached --stat

   # Identify changed files by category
   - Backend files (.cs, .csproj)
   - Frontend files (.ts, .tsx, .js, .jsx)
   - Documentation (.md)
   - Configuration (.json, .yml, .yaml)
   - Scripts (.sh, .ps1)
   ```

2. **AUTO-GENERATE COMMIT TYPE**
   Based on changes, determine commit type:
   - `feat`: New files or features added
   - `fix`: Bug fixes or corrections
   - `docs`: Documentation changes only
   - `style`: Formatting changes only
   - `refactor`: Code restructuring
   - `test`: Test additions/changes
   - `chore`: Maintenance tasks
   - `build`: Build system changes

3. **BUILD COMMIT MESSAGE**
   Automatically generate based on actual changes:
   ```
   <type>(<scope>): <auto-generated summary>

   Changes:
   - [Specific change 1]
   - [Specific change 2]
   - [Specific change 3]

   Files modified: X
   Insertions: +Y
   Deletions: -Z
   ```

4. **STAGE ALL CHANGES**
   ```bash
   git add -A
   ```

5. **CREATE COMMIT**
   ```bash
   git commit -m "[generated message]"
   ```

6. **SHOW RESULT**
   ```bash
   git log -1 --stat
   ```

### IMPLEMENTATION

When this command runs, I will:

1. Check git status to see what files have changed
2. Analyze the changes to understand what was modified
3. Generate an appropriate commit type and scope
4. Create a descriptive commit message based on actual changes
5. Stage and commit all changes
6. Display the commit details

### EXAMPLE OUTPUT

If you modified backend files and added tests:
```

Changes:
- Fixed validation in DrawingController.cs
- Added unit tests for SymbolService
- Updated error handling in BoQService
- Corrected async/await patterns

Files modified: 5
Insertions: +127
Deletions: -43
```

If you updated documentation:
```
docs(project): update README and task documentation

Changes:
- Added installation instructions to README
- Updated task-master documentation
- Fixed typos in CLAUDE.md
- Added examples to command docs

Files modified: 4
Insertions: +89
Deletions: -12
```

### USAGE

Simply run:
```bash
claude /do-quick-commit
```

The command will:
- Automatically analyze all changes
- Generate appropriate commit message
- Create the commit
- Show you what was committed

No additional input needed!
