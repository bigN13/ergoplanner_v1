# Task ID: 36
# Title: Create AI Chat Integration for P&ID Drawing Assistant
# Status: cancelled
# Dependencies: 26, 29, 30
# Priority: medium
# Description: Implement a conversational AI interface using Gemini API (or equivalent like OpenAI GPT-4/Claude) that enables natural language interaction with P&ID drawings, including creation, modification, querying, and intelligent assistance features.
# Details:
Create AIAssistantPanel component at frontend/src/components/drawing/AIAssistantPanel.tsx as a dockable panel integrated with the ReactFlow canvas. Implement AI service at backend/src/Ergoplanner.Application/Services/AIAssistantService.cs with Gemini/OpenAI/Claude API integration. Build natural language processing pipeline: parse commands using NLP models, map to drawing operations (add/modify/delete symbols, create connections, adjust properties), generate ReactFlow node/edge JSON from text descriptions. Implement command parser for instructions like 'Add centrifugal pump P-101 connected to valve V-102', 'Route pipe from tank T-201 to heat exchanger HX-301', 'What equipment is missing for this process?'. Create real-time preview system: show ghost nodes/edges before committing, highlight suggested placements, display confidence scores for AI suggestions. Add context management: maintain conversation history in frontend/src/store/ai-assistant-store.ts, track drawing state changes per conversation turn, implement multi-step operation support ('Now connect it to...', 'Make it bigger'). Integrate voice input using Web Speech API or Azure Speech Services, with push-to-talk and continuous listening modes. Implement drawing analysis features: compliance checking against ISA-5.1 and ISO 14617 standards, missing equipment detection based on process flow logic, optimization suggestions for pipe routing and layout. Create intelligent symbol placement: analyze existing layout for optimal positioning, maintain consistent spacing and alignment, suggest connection points based on symbol types. Build equipment specification recommendations: suggest pump types based on flow requirements, recommend valve types for process conditions, propose instrumentation based on control needs. Add documentation generation: create text descriptions from drawings, generate equipment lists with specifications, produce process narratives for training materials. Implement SignalR hub at backend/src/Ergoplanner.API/Hubs/AIAssistantHub.cs for real-time AI responses and drawing updates. Create prompt templates in backend/src/Ergoplanner.Application/AI/Prompts/ for different operations (creation, analysis, validation). Add rate limiting and token management for API calls. Implement caching layer using Redis for frequent queries and symbol mappings. Create error handling for ambiguous commands with clarification requests. Add undo/redo support for AI-generated changes. Store AI interaction logs for improvement and audit trails.

# Test Strategy:
Unit tests for command parsing, NLP interpretation, and drawing operation mapping. Integration tests for AI API calls with mock responses, real-time preview generation, and SignalR communication. E2E tests for complete conversation flows: creating drawings from scratch via chat, modifying existing drawings through natural language, voice input to drawing output. Performance tests for response time with complex drawings, concurrent AI requests handling, and context retention with long conversations. Validation tests for standards compliance checking, equipment recommendation accuracy, and drawing analysis correctness. Accessibility tests for screen reader compatibility with AI suggestions and keyboard navigation in chat interface.
